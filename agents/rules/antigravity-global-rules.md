# Global Agent Skills & Tools

You have access to a rich library of skills in `~/.agents/skills/`.
- `superpowers/`: Core AI agent workflows (brainstorming, TDD, debugging)
- `mattpocock-skills/`: Expert TypeScript, React, and Next.js guidelines
- `claude-plugins-official/`: Official tools
- `awesome-claude-skills/` & `claudekit-skills/`: Prompts and architecture

Always search this directory to load the relevant `SKILL.md` before starting complex tasks.
